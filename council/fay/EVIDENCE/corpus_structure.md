# Corpus structure — dated, day-organized, cross-language

**What this is:** the directory and file-naming structure of Fay's working corpus, showing real dated operational artifacts spanning months, produced on a recurring weekday cadence. Filenames and dates only.

**Redactions:** the household staff member's first name (used throughout the original filenames, e.g. `MENSAJE_<staff>_HOY_...`) is replaced with `<staff>` below. A second staff member's name appearing once (`MENSAJE_<staff2>_...`) is likewise redacted. No message content, no phone numbers, no WhatsApp IDs.

---

## Day-folder structure (`Fay's Corpus/<staff>/<Spanish weekday>/`)

Five weekday folders — Lunes, Martes, Miércoles, Jueves, Viernes — each holding, per dated cycle:

```
HOY_<date>_objetivos.md / .html / .pdf          — today's prioritized task list
MENSAJE_<staff>_HOY_<date>.md / .html / .pdf    — draft message (Spanish)
MENSAJE_<staff>_HOY_<date>_KREYOL.md / .txt     — final message, Haitian Creole
MENSAJE_<staff>_HOY_<date>_KREYOL_DEEP.*        — fuller Creole variant (some days)
```

Example, one representative day (Miércoles, April 15, 2026):
```
HOY_20260415_objetivos.html / .md / .pdf
MENSAJE_<staff>_HOY_20260415.html / .md / .pdf
MENSAJE_<staff>_HOY_20260415_KREYOL_DEEP.html / .md / .pdf
```

The Spanish and Creole versions of the same day's message exist as separate, independently named files — not one file with a language switch.

## Date range observed in this snapshot

Earliest dated artifact: **April 9, 2026** (`EMPLOYER_PRINCIPLES.md`). Corpus dispatch artifacts: **April 14 – July 20, 2026**, on a recurring Monday/Wednesday/Friday cadence with additional ad hoc dispatches (a payment reminder, a product-note follow-up). This is a snapshot of one project directory at one point in time, not a claim that nothing exists before or after these dates — but the density and regularity of dated, differently-purposed artifacts across more than three months is itself evidence of sustained real use, not a demo run.
