# Design principles — structural excerpt

**What this is:** the structural shape of Fay's operating principles (`DIGESTED_PRINCIPLES.md`, `EMPLOYER_PRINCIPLES.md`) — the coordination discipline behind the schedule → prioritize → dispatch flow. Household specifics (which rooms, which products, which routines) are intentionally not reproduced here; only the organizing structure is, as evidence of a designed system rather than ad hoc notes.

**Redactions:** all room-specific and task-specific household detail omitted. No staff names.

---

`DIGESTED_PRINCIPLES.md` is organized as: a small set of numbered top-level rules, a stated definition of "done" for the household's standard of clean, a fixed step-ordering for any coordination cycle (assess → prioritize → act → verify), and a priority ordering for *which* areas get attention first when time is limited. This is the same shape as the schedule → prioritize → translate → dispatch pipeline described in `ARCHITECTURE.md` — a fixed, repeatable procedure applied to whatever the current day's specifics are, rather than a one-off list.

`EMPLOYER_PRINCIPLES.md` documents an explicit employer-responsibility framework — write expectations down, communicate consistently, provide feedback — treating coordination-in-writing as a duty owed to the person doing the work, not just a convenience for the household. This is the operating rationale behind translating every dispatch into the staff's own language (see `DECISIONS.md` #1): the design treats clear, respectful, native-language communication as a baseline obligation, not an optional nicety.
