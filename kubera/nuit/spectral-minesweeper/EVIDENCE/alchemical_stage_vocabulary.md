# EVIDENCE — alchemical stage vocabulary (staging discipline, not mysticism)

**What this is:** the top-level stage directory names inside the Minesweeper
v3/v4/v5 working trees (5th-house-kubera, branch `cocktail-v3`). The naming is
alchemical (Calcination, Sublimation, Cibation, Conjunction, Fermentation) —
presented here as **vocabulary discipline**: a fixed, ordered set of stage names
used consistently across a long build so that "which phase is this artifact
from" is answerable by directory name alone, the same function a numbered
pipeline (Stage 1, Stage 2, ...) would serve, chosen instead for a program whose
own blueprint documents (see `NUIT_SPECTRAL_BLUEPRINT_v4`) explicitly reject any
single metaphor as foundational (§ 1.4) — the vocabulary is a label, not a claim
about the mechanism.

## Reading the sequence

The alchemical stages track the classical Magnum Opus ordering (calcination →
sublimation → fermentation → ... → projection = the completed result), used
here as an ordered checklist for a multi-week research pipeline: each stage
directory holds that phase's dispatch specs, intermediate artifacts, and
handoffs. `Cold_Firing_1` — the actual candidate-generation/validation runs —
sits inside `Conjunction` in the v3 tree, i.e. cold-firing is one stage's work
product, not the whole pipeline.

`Room_*` directories are exploratory side-experiments, kept alongside the main
stage sequence rather than merged into it or deleted — consistent with the
"state the wrong turn" discipline seen elsewhere in this repo (deprecated
mongoose kept in place, v2→v3→v4 blueprint self-corrections kept in writing).

No formula, threshold, or corpus-grammar content is shown — only directory
names, which is the extent of what "vocabulary discipline" claims to prove.
