**Kubera is also itself a shipped agent**, not just a namespace: the 5th-house quant-intelligence agent ("reconnaissance, verification, statistical rigor" — its own standing contract), grounded in the quant literature, reporting to Chris and Abraxas — the house-lord consulted on work-and-money decisions. Its contract carries two rules worth quoting: *"If a pipeline exists for a task, USE IT — no improvisation,"* and *"Agents do NOT give verdicts. The operators give verdicts. Agents give informed insights, observations, and appreciations."* Its vessel (persona/contract) file exists alongside the other house agents'; its doctrine and runtime were built and exercised (the mongoose-determinism and interpreter-never-fabricates-a-number disciplines documented under [nuit/spectral-minesweeper/](nuit/spectral-minesweeper/) are Kubera-house doctrine); it is currently **BUILT+DORMANT** as an interactive agent while the systems it supervised run on. Earlier in the record the same agent carried the name *Leona* — one agent, renamed, not two.
