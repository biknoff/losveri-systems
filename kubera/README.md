# kubera

This directory is where the trading systems live. "Kubera" is both the umbrella name for that work and, separately, a quant-research advisor agent (below). The trading system splits into [NUIT](nuit/) (discovery + supervision) and [HADIT](hadit/) (execution + product), on separate servers by design.

**Kubera is also itself a shipped agent**, not just a namespace: the quant-intelligence agent ("reconnaissance, verification, statistical rigor" — its own standing contract), grounded in the quant literature, reporting to Chris and Abraxas — the advisor consulted on work-and-money decisions. Its contract carries two rules worth quoting: *"If a pipeline exists for a task, USE IT — no improvisation,"* and *"Agents do NOT give verdicts. The operators give verdicts. Agents give informed insights, observations, and appreciations."* Its vessel (persona/contract) file exists alongside the other realm agents'; its doctrine and runtime were built and exercised (the mongoose-determinism and interpreter-never-fabricates-a-number disciplines documented under [nuit/spectral-minesweeper/](nuit/spectral-minesweeper/) are this realm's doctrine); it is currently **BUILT+DORMANT** as an interactive agent while the systems it supervised run on. Earlier in the record the same agent carried the name *Leona* — one agent, renamed, not two.
